# Support

Support for SmartImpact Figma Quick Edit Variables is available at:

[GitHub Issues](https://github.com/siit-dev/si-figma-quick-edit-variables/issues)

When reporting a problem, include:

- Figma desktop or web version.
- Operating system.
- Plugin version.
- Whether the issue is in Variables or Instance Diff.
- A minimal description of the selected layer or instance structure.
- Exact steps to reproduce the issue.
- A screenshot and plugin-console error, if available.

Do not post confidential Figma files, access tokens, credentials, or customer data. Reproduce the issue in a sanitized fixture whenever possible.

Security concerns must not be filed as public issues. Use
[GitHub's private vulnerability reporting](https://github.com/siit-dev/si-figma-quick-edit-variables/security/advisories/new).
