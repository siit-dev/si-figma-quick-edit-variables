# Security Policy

## Reporting A Vulnerability

Do not disclose security vulnerabilities in public GitHub issues.

Use [GitHub private vulnerability reporting](https://github.com/siit-dev/si-figma-quick-edit-variables/security/advisories/new) to send the report privately to the maintainers.

Include:

- A clear description of the issue and its impact.
- Reproduction steps or a minimal proof of concept.
- Affected plugin version.
- Any suggested remediation.

Do not include credentials, access tokens, confidential Figma files, or unrelated customer data.

The maintainers will assess the report and coordinate remediation and disclosure through the private advisory.
